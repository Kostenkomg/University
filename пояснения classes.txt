ПОСТРОЧНОЕ ПОЯСНЕНИЕ КОДА ФАЙЛА classes.py

1. Подключение модулей и базовый класс Card
- Строка 3: import random — подключает стандартный модуль для генерации случайных чисел (используется при вытягивании случайной карты из колоды и случайном ходе противника).
- Строка 5: class Card(object): — объявляет базовый класс Card, описывающий общие свойства и поведение любой карты в игре.
- Строка 6: cardtype = '_' — задаёт атрибут класса по умолчанию (символ типа обычной карты).
- Строка 8: def __init__(self, name, attack, defense): — конструктор карты, вызываемый при её создании; принимает имя, силу атаки и силу защиты.
- Строки 26–28: self.name = name, self.attack = attack, self.defense = defense — сохраняют переданные параметры в атрибуты конкретного экземпляра карты.
- Строка 30: def power(self, other_card): — метод расчёта боевой мощи текущей карты против карты противника (other_card).
- Строка 45: return self.attack - other_card.defense / 2 — вычисляет итоговую мощь по формуле: атака текущей карты минус половина защиты карты противника.
- Строка 48: def effect(self, other_card, player, opponent): — метод особого эффекта карты при розыгрыше. У базовой карты эффекта нет (пустой return).
- Строка 54: def __repr__(self): — специальный метод, который определяет, как карта будет отображаться при печати в виде текста.
- Строка 59: return '{} {} [{}, {}]'.format(...) — формирует строку вида «Имя Тип [Атака, Защита]».
- Строка 61: def copy(self): — метод создания независимой копии карты.
- Строка 65: return Card(self.name, self.attack, self.defense) — возвращает новый объект Card с такими же характеристиками.

2. Класс Player (Игрок)
- Строка 67: class Player(object): — объявляет класс игрока, который управляет своей колодой и картами в руке.
- Строка 68: def __init__(self, deck, name): — конструктор игрока, принимающий его колоду (deck) и имя (name).
- Строки 80–81: self.deck = deck и self.name = name — сохраняют колоду и имя внутри объекта игрока.
- Строка 82: self.hand = [self.deck.draw() for _ in range(5)] — формирует стартовую руку игрока (список self.hand), вытягивая 5 случайных карт из колоды с помощью генератора списка.
- Строка 84: def draw(self): — метод добора одной карты из колоды в руку.
- Строка 95: assert not self.deck.is_empty(), 'Колода кончилась!' — проверяет, что в колоде ещё остались карты; если колода пуста, вызывает ошибку AssertionError (которую перехватывает игровой цикл в cardgame.py).
- Строка 96: self.hand.append(self.deck.draw()) — вытягивает случайную карту из колоды и добавляет её в конец списка карт в руке.
- Строка 98: def play(self, card_index): — метод розыгрыша карты из руки по её порядковому номеру (индексу).
- Строка 111: return self.hand.pop(card_index) — удаляет карту с индексом card_index из списка self.hand и возвращает её.
- Строка 113: def display_hand(self): — метод красивого вывода в консоль всех карт, находящихся в руке игрока.
- Строки 117–120: цикл for card_index, displayed_card in zip(...) — перебирает индексы и строковые представления карт, добавляя отступ пробелами для ровного выравнивания столбцов.
- Строка 122: def play_random(self): — метод случайного хода (используется для бота-противника).
- Строка 126: return self.play(random.randrange(len(self.hand))) — выбирает случайный индекс в пределах текущей длины руки и разыгрывает эту карту.

3. Специальные карты (наследники класса Card)
- Строка 132: class BoyCard(Card): — создаёт подкласс карт «Мальчики», наследующий все свойства от Card.
- Строка 133: cardtype = '♂' — переопределяет символ типа карты.
- Строка 135: def effect(self, other_card, player, opponent): — переопределяет метод особого эффекта для карт типа BoyCard.
- Строки 149–151: цикл for _ in range(3): opponent.play(0); opponent.draw() — трижды сбрасывает первую (нулевую) карту из руки противника и тут же добирает ему новую карту из колоды.
- Строка 152: print('{} сбрасывает с руки 3 карты...'.format(opponent.name)) — выводит в консоль сообщение о срабатывании способности.
- Строка 154: def copy(self): — переопределяет копирование так, чтобы копия тоже была объектом BoyCard.

- Строка 160: class GirlCard(Card): — создаёт подкласс карт «Девочки», наследующий от Card.
- Строка 161: cardtype = '♀' — переопределяет символ типа карты.
- Строка 163: def effect(self, other_card, player, opponent): — переопределяет эффект для карт типа GirlCard.
- Строка 176: other_card.attack, other_card.defense = other_card.defense, other_card.attack — меняет местами значения атаки и защиты у карты противника (other_card).
- Строка 178: def copy(self): — возвращает копию объекта класса GirlCard.

- Строка 184: class TeacherCard(Card): — создаёт подкласс карт «Преподаватели», наследующий от Card.
- Строка 185: cardtype = '✪' — переопределяет символ типа карты.
- Строка 187: def effect(self, other_card, player, opponent): — переопределяет эффект для карт типа TeacherCard.
- Строка 204: orig_opponent_deck_length = len(opponent.deck.cards) — запоминает исходное количество карт в колоде противника до применения эффекта.
- Строки 205–207: цикл for card in player.deck.cards: — проходит по всем оставшимся картам в колоде игрока и прибавляет к их атаке и защите соответствующие характеристики карты противника (other_card).
- Строки 208–211: opponent.deck.cards = [...] — фильтрует колоду противника с помощью генератора списка: оставляет только те карты, у которых ни атака, ни защита не совпадают с атакой и защитой other_card (остальные удаляются).
- Строка 212: discarded = orig_opponent_deck_length - len(opponent.deck.cards) — вычисляет, сколько карт пропало из колоды противника.
- Строки 213–215: if discarded: print(...) — если пропала хотя бы одна карта, выводит сообщение с именем противника и числом потерянных карт.
- Строка 217: def copy(self): — возвращает копию объекта класса TeacherCard.

4. Классы Deck (Колода) и Game (Игровой процесс)
- Строка 225: class Deck(object): — класс колоды карт.
- Строка 226: def __init__(self, cards): — сохраняет переданный список карт в self.cards.
- Строка 233: def draw(self): — метод вытягивания случайной карты из колоды.
- Строки 237–239: assert self.cards ... rand_index = random.randrange(len(self.cards)); return self.cards.pop(rand_index) — проверяет, что колода не пуста, выбирает случайный индекс и извлекает карту из списка.
- Строка 241: def is_empty(self): — возвращает True, если в колоде 0 карт, и False в противном случае.
- Строка 244: def copy(self): — создаёт глубокую копию колоды, копируя каждую карту внутри неё через card.copy().

- Строка 250: class Game(object): — класс, управляющий правилами раунда и подсчётом очков.
- Строка 252: win_score = 8 — задаёт количество очков, необходимое для победы в партии.
- Строка 254: def __init__(self, player1, player2): — сохраняет обоих игроков и обнуляет их счётчики очков (self.p1_score = 0, self.p2_score = 0).
- Строка 262: def play_round(self, p1_card, p2_card): — проводит один игровой раунд между двумя выбранными картами.
- Строки 266–267: p1_card.effect(...) и p2_card.effect(...) — по очереди активирует особые способности обеих карт до расчёта их силы.
- Строки 268–269: p1_power = ... и p2_power = ... — вычисляет боевую мощь каждой карты с учётом уже применённых эффектов.
- Строки 270–280: блок if / elif / else — сравнивает мощь карт, начисляет 1 очко победителю раунда и определяет текстовый результат ('победа', 'поражение' или 'ничья').
- Строки 282–284: print(...) — выводит итоги раунда и характеристики сыгранных карт.
- Строка 287: def game_won(self): — проверяет, набрал ли кто-то 8 очков (win_score); возвращает 0 (игра продолжается), 1 (победил первый игрок) или 2 (победил второй игрок).
- Строка 295: def display_scores(self): — печатает текущий счёт обоих игроков.
